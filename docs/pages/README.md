# Page maps

`chapter|term` → printed textbook page (Steam Systems, 2019) where the term is defined. Built from the chapter PDFs jake uploads, checked against page images where the scan text was unclear. The bundled course file carries these as each card's `ref`.

New chapter: add `chN-pages.json`, regenerate the course file with `version` + 1, and hand it to jake to tap (no rebuild needed). Card and question text is never edited.
